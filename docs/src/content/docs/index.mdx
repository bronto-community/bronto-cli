`bronto` is a command-line client for the [Bronto](https://bronto.io) observability
platform. It wraps Bronto's REST and ingestion APIs, so anything you do in the web app
you can also do in a shell script, a CI job, or an agent's tool call.

<Tape name="quickstart" title="Log in, find the failing service, and pull its errors" />

## What you can do

<CardGrid>
	<Card title="Search logs" icon="magnifier">
		Run one-shot queries with `bronto search`, or let filter flags like `--eq` and `--gt`
		write the WHERE clause for you. [Searching](/guides/searching/)
	</Card>
	<Card title="Follow live" icon="rocket">
		`bronto tail` streams new events like `tail -f`, or redraws a live group-by every few
		seconds. [Live tail](/guides/live-tail/)
	</Card>
	<Card title="Explore traces" icon="random">
		See a trace's waterfall, latency per service, and the call-tree shape merged across
		many traces.
		[Traces](/guides/traces/)
	</Card>
	<Card title="Manage resources" icon="list-format">
		Datasets, monitors, dashboards, users, API keys and more share one
		`list | get | create | update | delete` pattern. [Resources](/guides/resources/)
	</Card>
	<Card title="Script it" icon="seti:shell">
		JSONL when piped, a JSON error envelope, `--jq`, `--dry-run`, and documented exit
		codes. [Scripting and agents](/guides/scripting/)
	</Card>
	<Card title="Run it in CI" icon="setting">
		Read the key from the environment instead of a keychain, or use the container image,
		which has no shell. [CI/CD](/guides/ci-cd/)
	</Card>
</CardGrid>
