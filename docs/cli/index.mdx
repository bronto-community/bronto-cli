`bronto` is a command-line client for the [Bronto](https://bronto.io) observability
platform. It wraps Bronto's REST and ingestion APIs, so anything you do in the web app
you can also do in a shell script, a CI job, or an agent's tool call. It's a single
binary with scriptable output and stable exit codes.

## What you can do

<CardGroup cols={2}>
  <Card title="Search logs" icon="magnifying-glass" href="/cli/guides/searching">
    Run one-shot queries with `bronto search`, or let filter flags like `--eq` and `--gt`
    write the WHERE clause for you.
  </Card>
  <Card title="Follow live" icon="rocket" href="/cli/guides/live-tail">
    `bronto tail` streams new events like `tail -f`, or redraws a live group-by every few
    seconds.
  </Card>
  <Card title="Explore traces" icon="diagram-project" href="/cli/guides/traces">
    See a trace's waterfall, latency per service, and the call-tree shape merged across
    many traces.
  </Card>
  <Card title="Manage resources" icon="list" href="/cli/guides/resources">
    Datasets, monitors, dashboards, users, API keys and more share one
    `list | get | create | update | delete` pattern.
  </Card>
  <Card title="Script it" icon="terminal" href="/cli/guides/scripting">
    JSONL when piped, a JSON error envelope, `--jq`, `--dry-run`, and documented exit
    codes.
  </Card>
  <Card title="Run it in CI" icon="gear" href="/cli/guides/ci-cd">
    Read the key from the environment instead of a keychain, or use the container image,
    which has no shell.
  </Card>
</CardGroup>
