## bronto sso idps export

Writes an SSO identity provider as infrastructure-as-code (HCL) on stdout, to check into version control
and manage with the Bronto Terraform provider. The output is text, so -o does not apply.
The client secret is never exported: a comment marks where to set it.

```sh
bronto sso idps export <idp> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--format` |  | string | `terraform` | export format: terraform or opentofu |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto sso idps export Google > idp.tf
```

## bronto sso mappings export

Writes the organization's SSO mappings as infrastructure-as-code (HCL) on stdout, to check into version control
and manage with the Bronto Terraform provider. The output is text, so -o does not apply.
The export is always the complete mapping list, not one mapping.

```sh
bronto sso mappings export [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--format` |  | string | `terraform` | export format: terraform or opentofu |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto sso mappings export > sso_mappings.tf
```
