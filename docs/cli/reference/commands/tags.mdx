A tag is a name=value pair on one entity; a name is unique per entity.
The write verbs take the entity's type (api\_key, dashboard, integration, log, monitor, saved\_search, slo, user, widget),
then the entity by id, or by name where the CLI has a command for that
type (log is a dataset), then the tag. Entity types are accepted in any
case.

```sh
bronto tags <command> [flags]
```

#### Subcommands

| Command | Description |
| --- | --- |
| [`bronto tags create`](/cli/reference/commands/tags#bronto-tags-create) | Add a tag to an entity |
| [`bronto tags delete`](/cli/reference/commands/tags#bronto-tags-delete) | Remove a tag from an entity |
| [`bronto tags list`](/cli/reference/commands/tags#bronto-tags-list) | List tag names, their values, and how many entities of each type carry them |
| [`bronto tags update`](/cli/reference/commands/tags#bronto-tags-update) | Change the value of a tag on an entity |

Also accepts the [global flags](/cli/reference/commands/global-flags).

## bronto tags create

The tag is given as name=value.

```sh
bronto tags create <entity-type> <entity> <tag> [flags]
```

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto tags create dashboard "Checkout overview" team=checkout
```

## bronto tags delete

Remove a tag from an entity

```sh
bronto tags delete <entity-type> <entity> <tag-name> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--yes` |  | bool |  | skip the confirmation prompt |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto tags delete dashboard "Checkout overview" team --yes
```

## bronto tags list

Lists the tags in use. The table's type and entities columns are derived from the API's rows: with -o json, --fields selects the API's own keys (name, value), and the entity ids are under value.

```sh
bronto tags list [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--entity-type` |  | string |  | only tags on this entity type |
| `--name` |  | string |  | only tags with this name |
| `--value` |  | string |  | only tags with this value |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto tags list
bronto tags list --name team --entity-type dashboard
```

## bronto tags update

The tag is given as name=value.

```sh
bronto tags update <entity-type> <entity> <tag> [flags]
```

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto tags update dashboard "Checkout overview" team=checkout
```
