Manage Bronto credentials and profiles

<Tip>
The Bronto docs explain the platform concept behind this command: [docs.bronto.io/Account-Management/API-Keys](https://docs.bronto.io/Account-Management/API-Keys)
</Tip>

```sh

```

## bronto auth login

Authenticate and store a Bronto API key

```sh

```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--key-stdin` |  | bool |  | read the API key from stdin instead of prompting |
