## bronto query check

Validate a query expression before using it

```sh
bronto query check <query> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--dataset` | `-d` | string |  | dataset (name or UUID) to check field names against |
| `--strict` |  | bool |  | fail on unknown fields instead of warning (for CI) |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto query check "status >= 500 AND level = 'error'"
bronto query check "stauts >= 500" -d prod/payments-api   # catches the typo
```
