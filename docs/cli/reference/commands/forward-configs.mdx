## bronto forward-configs create

Create a forward config

```sh
bronto forward-configs create [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--field` | `-f` | stringArray |  | request body field as key=value; values parse as JSON when possible (repeatable) |
| `--input` |  | string |  | read the request body from a file, or - for stdin |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto forward-configs create -f name=<name> -f all_logs=true -f compression=GZIP \
    -f 'destination={"destination_type":"S3","bucket":"<bucket>"}'
bronto forward-configs create --input body.json
```

## bronto forward-configs test

Check that Bronto can write to a forward config's S3 destination

<Tip>
- **Platform docs:** [docs.bronto.io/core-features/log-forwarding](https://docs.bronto.io/core-features/log-forwarding)
- **API reference:** [docs.bronto.io/api-reference/forward/test-access-to-the-destination](https://docs.bronto.io/api-reference/forward/test-access-to-the-destination)
</Tip>

```sh
bronto forward-configs test [forward-config] [--bucket <bucket>] [--prefix <prefix>] [--storage-class <class>] [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--bucket` |  | string |  | S3 bucket to test (overrides the forward config's) |
| `--prefix` |  | string |  | key prefix for the test object (overrides the forward config's) |
| `--storage-class` |  | string |  | S3 storage class: STANDARD, STANDARD\_IA or GLACIER\_IR |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto forward-configs test archive
bronto forward-configs test --bucket my-archive-bucket --prefix bronto/
```
