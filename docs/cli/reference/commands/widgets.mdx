## bronto widgets attach-widgets

Attach widgets to a group widget. The group widget and each widget resolve by id or unique name.

This applies only to group widgets (type group), which hold other widgets.
To put widgets on a dashboard, use 'bronto dashboards attach-widgets'.

The API answers with no body, so the command confirms on stderr. With -o json,
-o jsonl or --jq it prints the updated widget instead.

```sh
bronto widgets attach-widgets <widget> --widget-ids <id,...> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--widget-ids` |  | strings |  | widget IDs or names to attach (comma-separated or repeated) |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto widgets attach-widgets <widget> --widget-ids <id>,<id>
```

## bronto widgets query

Evaluates every metric definition in a widget's metric\_ids, like
'bronto metrics definitions query' does for one, and prints their series in
one table with a DEFINITION column. -o json prints an object mapping each
definition id to its raw /timeseries response.

The widget can be an id or a unique name.

```sh
bronto widgets query <widget> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--from` |  | string |  | absolute start (RFC3339) |
| `--limit` |  | int |  | maximum groups per grouped query, 1-1000 (default: the API's 100) |
| `--since` |  | string |  | relative lookback: 30m, 24h, 7d, 1h30m (default 24h) |
| `--slices` |  | int | `24` | time buckets per series (the TREND sparkline's resolution) |
| `--time-range` |  | string |  | relative range in the API's words, e.g. "Last 24 hours" (instead of --since) |
| `--to` |  | string |  | absolute end (RFC3339), requires --from |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto widgets query "Checkout requests"
bronto widgets query <id> --since 7d -o json
```
