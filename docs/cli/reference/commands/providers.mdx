## bronto providers create

Create a provider integration

```sh
bronto providers create [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--field` | `-f` | stringArray |  | request body field as key=value; values parse as JSON when possible (repeatable) |
| `--input` |  | string |  | read the request body from a file, or - for stdin |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto providers create -f provider=aws-devops-agent -f url=<url> -f secret=<secret> \
    -f auth_type=hmac
bronto providers create --input body.json
```

## bronto providers export

Writes a provider integration as infrastructure-as-code (HCL) on stdout, to check into version control
and manage with the Bronto Terraform provider. The output is text, so -o does not apply.

```sh
bronto providers export <id> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--format` |  | string | `terraform` | export format: terraform or opentofu |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto providers export <id> > provider_integration.tf
```
