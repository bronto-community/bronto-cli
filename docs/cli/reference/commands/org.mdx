Show or update the organization record

```sh
bronto org <command> [flags]
```

#### Subcommands

| Command | Description |
| --- | --- |
| [`bronto org show`](/cli/reference/commands/org#bronto-org-show) | Show the organization record |
| [`bronto org update`](/cli/reference/commands/org#bronto-org-update) | Update the organization's name and billing emails |

Also accepts the [global flags](/cli/reference/commands/global-flags).

## bronto org show

Prints the organization's customer record: its ids, name, region, billing emails and the organizations of the same customer.

```sh
bronto org show [flags]
```

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto org show
bronto org show --jq .customer_name
```

## bronto org update

Changes the customer record. The API takes customer\_name and billing\_emails, and documents both as required: send the current value of the one you keep (see 'bronto org show').

```sh
bronto org update [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--field` | `-f` | stringArray |  | request body field as key=value; values parse as JSON when possible (repeatable) |
| `--input` |  | string |  | read the request body from a file, or - for stdin |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto org update -f customer_name=<name> -f 'billing_emails=["<email>"]'
bronto org update --input org.json
```
