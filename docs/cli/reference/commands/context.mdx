Show events around a specific log event

<Tip>
- **Platform docs:** [docs.bronto.io/api-reference/context/overview](https://docs.bronto.io/api-reference/context/overview)
- **API reference:** [docs.bronto.io/api-reference/context/retrieve-contextual-information-for-a-given-sequence-and-log](https://docs.bronto.io/api-reference/context/retrieve-contextual-information-for-a-given-sequence-and-log)
</Tip>

```sh
bronto context [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--dataset` | `-d` | string |  | dataset name or UUID that holds the event (required) |
| `--direction` |  | string | `both` | which side of the event to show: before, after, or both |
| `--limit` | `-n` | int | `50` | maximum events on each side |
| `--sequence` |  | int |  | sequence number of the event to look around (required) |
| `--timestamp` |  | int |  | timestamp of the event in Unix milliseconds (required) |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto context --sequence 111721913 -d <dataset> --timestamp 1711535140632
bronto context --sequence 42 -d <dataset> --timestamp 1711535140632 --direction before
```
