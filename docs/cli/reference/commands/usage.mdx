Shows organization-wide ingestion, search, and export usage over a time period.

For per-dataset usage, run: bronto api GET /usage/organizations/logs

<Tip>
- **Platform docs:** [docs.bronto.io/api-reference/usage/overview](https://docs.bronto.io/api-reference/usage/overview)
- **API reference:** [docs.bronto.io/api-reference/usage/get-usage-for-log-id](https://docs.bronto.io/api-reference/usage/get-usage-for-log-id)
</Tip>

```sh
bronto usage [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--since` |  | string | `7d` | relative lookback (single unit: 1h, 7d) |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto usage --since 7d
bronto usage --since 1h
```
