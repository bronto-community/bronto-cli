## bronto policies list

Lists the policies associated with one resource, given by id. The resource type is the API's name for it: logset for a dataset (the API answers 400 to the spec's other example, dataset).

```sh
bronto policies list <resource-type> <resource-id> [flags]
```

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto policies list logset <dataset-id>
```
