## bronto slack create

Create a Slack integration

```sh
bronto slack create [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--field` | `-f` | stringArray |  | request body field as key=value; values parse as JSON when possible (repeatable) |
| `--input` |  | string |  | read the request body from a file, or - for stdin |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto slack create -f name=<name> -f workspace_id=<workspace-id> -f 'channels=["<channel>"]'
bronto slack create --input body.json
```

## bronto slack export

Writes a Slack integration as infrastructure-as-code (HCL) on stdout, to check into version control
and manage with the Bronto Terraform provider. The output is text, so -o does not apply.

```sh
bronto slack export <id> [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--format` |  | string | `terraform` | export format: terraform or opentofu |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto slack export <id> > slack_integration.tf
```

## bronto slack workspaces

Lists and removes the Slack workspaces connected to Bronto. Connect one in the web UI;
deleting one here does not uninstall the Bronto app from Slack.

```sh
bronto slack workspaces <command> [flags]
```
