Lists the field names (top keys) in a dataset, with a sample of the values
seen for each. Pass a name-filter to keep only fields whose name contains it
(case-insensitive). Use it to find the exact spelling of a field before you
write a search query.

<Tip>
- **Platform docs:** [docs.bronto.io/Search-and-Visualize/Log-Search](https://docs.bronto.io/Search-and-Visualize/Log-Search)
- **API reference:** [docs.bronto.io/api-reference/top-keys/retrieve-top-keys-for-logs](https://docs.bronto.io/api-reference/top-keys/retrieve-top-keys-for-logs)
</Tip>

```sh
bronto fields [name-filter] [flags]
```

#### Flags

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--dataset` | `-d` | string |  | dataset name or UUID (omit to cover all datasets) |
| `--limit` | `-n` | int |  | maximum keys to return |
| `--since` |  | string | `1h` | relative lookback (single unit: 30s, 15m, 1h, 2d) |

Also accepts the [global flags](/cli/reference/commands/global-flags).

#### Examples

```sh
bronto fields -d <dataset> --since 1h
bronto fields -d <dataset> model      # fields with "model" in the name
bronto fields --since 15m -n 20
```
