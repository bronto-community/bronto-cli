This page lists every operation of the [Bronto API](https://docs.bronto.io/api-reference/introduction) and the `bronto` command that calls it. It is generated from the OpenAPI spec the CLI is built against and from the CLI's own code, so it matches the binary built from the same commit.

**103 of 147 operations have a dedicated command.** The other 44, and every endpoint the API adds later, are reachable with [`bronto api`](/cli/extend/api), which calls any endpoint with the same credentials, region, retries, and output formatting as the rest of the CLI:

```sh
bronto api GET /users/all
```

A command is listed when it exposes what the endpoint does. Endpoints a command only calls along the way, such as resolving a dataset name to its id, are not listed under it. A command group such as `bronto traces` calls the endpoint from its subcommands.
