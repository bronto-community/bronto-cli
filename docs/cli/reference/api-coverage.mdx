The bronto CLI has commands for most of the [Bronto API](https://docs.bronto.io/api-reference/introduction). This page lists the commands for each part of the API, then what the CLI doesn't support yet. You can call those endpoints with [`bronto api`](/cli/extend/api), which uses the same credentials and region as every other command:

```sh
bronto api GET /users/all
```

The page is generated from the OpenAPI spec the CLI is built against, so it matches the CLI released from the same commit.

## Not supported yet

| Category | What | Endpoint |
| --- | --- | --- |
| Users | List all users | `GET /users/all` |
|  | Read a user's preferences | `GET /users/{userId}/preferences` |
|  | Change a user's preferences | `PATCH /users/{userId}/preferences` |
| Datasets | Resolve datasets | `POST /datasets/resolve` |
| Access | Switch a user's active organization | `POST /organizations/{orgId}/access/user/{userId}/switch` |
| Widgets | Change a widget's layout | `PATCH /widgets/{id}` |
| AI | Explain an error with AI | `GET /explain-error` |
|  | Suggest a widget from a prompt with AI | `GET /widget-creation-assistant` |
| Policies | List the policies on a resource | `GET /policies/resources/{resource_type}/{resource_id}` |
| Patterns | Get server-side log patterns and their templates | `POST /patterns` |
