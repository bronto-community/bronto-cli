The bronto CLI has commands for most of the [Bronto API](https://docs.bronto.io/api-reference/introduction). This page lists the commands for each part of the API, then what the CLI doesn't support yet. You can call those endpoints with [`bronto api`](/cli/extend/api), which uses the same credentials and region as every other command:

```sh
bronto api GET /users/all
```

The page is generated from the OpenAPI spec the CLI is built against, so it matches the CLI released from the same commit.

## Not supported yet

| Category | What | Endpoint |
| --- | --- | --- |
| Users | List all users | `GET /users/all` |
|  | Export a user | `GET /users/{userId}/export` |
|  | Read a user's preferences | `GET /users/{userId}/preferences` |
|  | Change a user's preferences | `PATCH /users/{userId}/preferences` |
|  | List the organizations a user can access | `GET /users/{userId}/access` |
| Groups | Export a group | `GET /groups/{groupId}/export` |
| Datasets | Resolve datasets | `POST /datasets/resolve` |
| Monitors | Export a monitor | `GET /monitors/{monitorId}/export` |
| Dashboards | Export a dashboard as Terraform | `GET /dashboards/{dashboardId}/export` |
| Access | Grant a user or group access to an organization | `POST /organizations/{orgId}/access/{entityType}/{entityId}` |
|  | Revoke a user's or group's access to an organization | `DELETE /organizations/{orgId}/access/{entityType}/{entityId}` |
|  | List who has access to an organization | `GET /organizations/{orgId}/access` |
|  | Check whether a user or group has access to an organization | `GET /organizations/{orgId}/access/{entityType}/{entityId}/check` |
|  | Switch a user's active organization | `POST /organizations/{orgId}/access/user/{userId}/switch` |
| Widgets | Change a widget's layout | `PATCH /widgets/{id}` |
| Integrations | Export a Slack integration | `GET /integrations/slack/{slack_id}/export` |
|  | List Slack workspaces | `GET /integrations/slack/workspaces` |
|  | Remove a Slack workspace | `DELETE /integrations/slack/workspaces/{workspace_id}` |
|  | Export a webhook | `GET /integrations/webhooks/{webhook_id}/export` |
|  | List provider integrations, such as AWS DevOps Agent | `GET /integrations/providers` |
|  | Create a provider integration | `POST /integrations/providers` |
|  | Get a provider integration | `GET /integrations/providers/{provider_id}` |
|  | Update a provider integration | `PUT /integrations/providers/{provider_id}` |
|  | Delete a provider integration | `DELETE /integrations/providers/{provider_id}` |
|  | Export a provider integration | `GET /integrations/providers/{provider_id}/export` |
| SSO | Export an SSO identity provider | `GET /sso/idps/{idp_name}/export` |
|  | Export SSO mappings | `GET /sso/mappings/export` |
| Customer | Read the organization's customer record | `GET /customer` |
|  | Update the organization's customer record | `PATCH /customer` |
| Tags | Update a tag | `PUT /tags` |
|  | Create a tag | `POST /tags` |
|  | Delete a tag | `DELETE /tags` |
|  | List tags | `GET /tags/search` |
| AI | Explain an error with AI | `GET /explain-error` |
|  | Suggest a widget from a prompt with AI | `GET /widget-creation-assistant` |
| Policies | List the policies on a resource | `GET /policies/resources/{resource_type}/{resource_id}` |
| Patterns | Get server-side log patterns and their templates | `POST /patterns` |
